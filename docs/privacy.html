Política de Privacidade

Inbox Digest — atualizada em 7 de setembro de 2026

O Inbox Digest é uma ferramenta pessoal, operada pelo próprio usuário, que resume a caixa de entrada dele e entrega esse resumo no Telegram. Não há outros usuários, não há empresa por trás e nenhum dado é comercializado.

Dados do Google acessados

A ferramenta usa a Gmail API com o escopo https://www.googleapis.com/auth/gmail.modify e acessa:

  • Cabeçalhos das mensagens: remetente, assunto, data e o cabeçalho List-Unsubscribe.
  • Trecho de pré-visualização (snippet) fornecido pela própria API.

O corpo completo das mensagens e os anexos não são baixados — as requisições usam o formato metadata, que não retorna esse conteúdo.

Como os dados são usados

  • Selecionar mensagens conforme as regras de busca definidas pelo usuário.
  • Montar um resumo em texto e enviá-lo ao canal privado do usuário no Telegram.
  • Aplicar uma etiqueta às mensagens já resumidas, para não repeti-las.

A escrita se limita a aplicar essa etiqueta. A ferramenta não envia, não responde, não move e não exclui e-mails.

Armazenamento e retenção

Nenhum conteúdo de e-mail é gravado em banco de dados, arquivo ou log. Os dados existem apenas na memória durante a execução e são descartados ao final. O único registro persistente é a etiqueta aplicada dentro da própria conta Gmail do usuário.

As credenciais de acesso (token OAuth) ficam guardadas de forma cifrada em GitHub Actions Secrets, acessíveis somente ao dono do repositório.

Compartilhamento

Os dados não são vendidos, alugados nem compartilhados. O resumo é transmitido a um único destino, escolhido pelo usuário: o Telegram, por meio da API oficial de bots, sobre conexão HTTPS. Não há analytics, rastreadores, publicidade ou serviços de terceiros.

O uso dos dados obtidos das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado (Limited Use).

Revogação de acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions. A revogação invalida o token imediatamente e interrompe qualquer acesso futuro.

Privacy Policy

Inbox Digest — updated September 7, 2026

Inbox Digest is a personal, self-operated tool that summarizes its own user's inbox and delivers that summary to Telegram. There are no other users, no company behind it, and no data is sold.

Google data accessed

The tool uses the Gmail API with the scope https://www.googleapis.com/auth/gmail.modify and accesses message headers (sender, subject, date, List-Unsubscribe) and the API-provided snippet. Full message bodies and attachments are never downloaded — requests use metadata format, which does not return them.

How the data is used

To select messages according to user-defined search rules, compose a text summary sent to the user's own private Telegram chat, and apply a label to already-summarized messages so they are not repeated. Write access is limited to applying that label: the tool does not send, reply to, move, or delete email.

Storage and retention

No email content is written to any database, file, or log. Data exists only in memory during a run and is discarded when it ends. The only persistent record is the label applied inside the user's own Gmail account. OAuth credentials are stored encrypted in GitHub Actions Secrets, accessible only to the repository owner.

Sharing

Data is not sold, rented, or shared. The summary is transmitted to a single user-chosen destination — Telegram, via its official Bot API over HTTPS. There are no analytics, trackers, ads, or third-party services. Use of data obtained from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions, which invalidates the token immediately.
